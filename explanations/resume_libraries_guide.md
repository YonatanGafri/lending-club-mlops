# ספריות ה-Data Science בפרויקט - המדריך המלא לקורות חיים וראיונות

מסמך זה נועד להעניק לך שליטה עמוקה בספריות בהן השתמשת בפרויקט. הוא כולל פירוט נרחב של הפונקציות השימושיות ביותר לכל ספרייה (מעבר לדוגמאות ספציפיות), הסבר מפורט על הפרמטרים וערכי החזרה, ודוגמאות מתוך הקוד שלך כדי לקשר את התיאוריה לפרקטיקה.

## הבהרה חשובה: Pandas לעומת Polars ולמה Matplotlib מעדיפה Pandas?

בפרויקט השתמשת ב-**Polars** כדי לקרוא את קובץ הנתונים הענק ולבצע עליו פעולות סינון כבדות. Polars היא ספרייה מודרנית שנכתבה ב-Rust, היא פועלת במקביל (Multi-threaded) ויעילה משמעותית בזיכרון לעומת Pandas.

**האובייקט ש-Polars מחזירה:** `polars.DataFrame`. אובייקט זה ממוטב למהירות ואינו כולל "אינדקס" (Index) כמו ב-Pandas. 

**האובייקט ש-Pandas מחזירה:** `pandas.DataFrame` (טבלה דו-ממדית) ו-`pandas.Series` (עמודה בודדת). לאובייקטים אלו יש תמיד **אינדקס (Index)**, המגדיר שֵם או מספר לכל שורה.

**למה עדיף להעביר את האובייקט של Pandas ל-Matplotlib ול-Seaborn?**
ספריות הוויזואליזציה המובילות בפייתון (Matplotlib ו-Seaborn) פותחו הרבה לפני ש-Polars הייתה קיימת. הן נבנו מתוך מחשבה לעבוד בצורה חלקה וטבעית עם המבנים של Pandas:
1. **האינדקס של Pandas:** Matplotlib יודעת לקחת את האינדקס של טבלת Pandas ולהפוך אותו אוטומטית לציר ה-X.
2. **אינטגרציה ב-Seaborn:** הפונקציות של Seaborn מצפות לקבל אובייקט `pandas.DataFrame` בפרמטר ה-`data=` שלהן, מה שמאפשר לקרוא לעמודות פשוט בשמן (למשל `x='term', y='target'`). העברת אובייקט של Polars ישירות עלולה לגרום לשגיאות מכיוון ש-Seaborn מנסה להשתמש במתודות שקיימות רק ב-Pandas.
*לכן, בפרויקט שלך רואים את הפקודה `train_df.to_pandas()` רגע לפני שמתחילים לצייר גרפים!*

## 1. Pandas (`pd`)
הספרייה הקלאסית והנפוצה ביותר בתעשייה לניתוח וניקוי נתונים טבלאיים (Data Wrangling).

### פונקציות מרכזיות ושימושיות:
*   **`pd.read_csv(filepath, sep, usecols)`**
    *   **עושה:** טוענת קובץ נתונים טקסטואלי למבנה נתונים בפייתון.
    *   **פרמטרים:** `filepath` (נתיב לקובץ), `sep` (תו מפריד, דיפולט פסיק), `usecols` (רשימת עמודות לטעינה, לחסכון בזיכרון).
    *   **מחזירה:** אובייקט `pandas.DataFrame`.
*   **`df.info()` / `df.describe()`**
    *   **עושה:** `info` מחזירה מידע על סוגי הנתונים וערכים חסרים (Nulls). `describe` מחזירה סטטיסטיקה תיאורית (ממוצע, חציון, סטיות תקן) לעמודות נומריות.
    *   **מחזירה:** פלט למסך / אובייקט DataFrame של סטטיסטיקות.
*   **`df.groupby(by).agg(func)`**
    *   **עושה:** מקבצת שורות לפי ערכים משותפים בעמודה מסוימת, ומבצעת עליהן פעולת חישוב.
    *   **פרמטרים:** `by` (שם העמודה או רשימת עמודות לקיבוץ), `func` (פונקציית החישוב - למשל `'mean'`, `'sum'`, `'count'`).
    *   **מחזירה:** `DataFrame` מקובץ שבו הערכים הייחודיים הפכו לאינדקס.
*   **`df.fillna(value, method)` / `df.dropna(how)`**
    *   **עושה:** מטפלות בערכים חסרים (NaN). `fillna` ממלאת אותם בערך קבוע, `dropna` מוחקת שורות או עמודות שיש בהן ערכים חסרים.
    *   **פרמטרים:** `value` (הערך למילוי), `method` (שיטת מילוי כמו 'ffill' - העתקת ערך קודם), `how` ('any' מוחק שורה אם יש חסר אחד, 'all' רק אם כולה חסרה).
    *   **מחזירה:** אובייקט `DataFrame` חדש ומתוקן.
*   **`df.apply(func, axis)`**
    *   **עושה:** מפעילה פונקציה מותאמת אישית (כמו lambda) על כל שורה או כל עמודה.
    *   **פרמטרים:** `func` (הפונקציה להפעלה), `axis` (0 לעמודות, 1 לשורות).
    *   **מחזירה:** `Series` או `DataFrame`.

**דוגמאות מהפרויקט שלך:**
```python
# המרה לצורך ויזואליזציה וחישוב מולטי-קולינאריות
train_df_pd = train_df.to_pandas()
df_sampled = train_df.select(cols_to_sample).sample(n=50000, seed=42).to_pandas()
full_corr_matrix = df_full_num.corr() # הפעלת מתודה פנימית של Pandas לחישוב מתאם
```

## 2. Polars (`pl`)
ספרייה סופר-מהירה לעיבוד נתונים בזכות כתיבה ב-Rust ושימוש בביטויים (Expressions) מקביליים.

### פונקציות מרכזיות ושימושיות:
*   **`pl.read_csv(filepath, ignore_errors)`**
    *   **עושה:** קוראת נתונים במהירות עצומה.
    *   **פרמטרים:** `ignore_errors` (מדלג על שורות שלא מצייתות לפורמט במקום להקריס את הסקריפט).
    *   **מחזירה:** `polars.DataFrame`.
*   **`df.select(exprs)`**
    *   **עושה:** בוחרת עמודות ספציפיות, תוך אפשרות להפעיל עליהן ביטויים מתמטיים באותו הזמן.
    *   **פרמטרים:** ביטויי Polars (`pl.col('name')`).
    *   **מחזירה:** `polars.DataFrame` עם העמודות שנבחרו.
*   **`df.filter(condition)`**
    *   **עושה:** מסננת שורות שאינן מקיימות תנאי מסוים (המקבילה של Polars ל- boolean indexing ב-Pandas).
    *   **פרמטרים:** תנאי, למשל `pl.col('age') > 18`.
    *   **מחזירה:** `polars.DataFrame` מסונן.
*   **`df.with_columns(exprs)`**
    *   **עושה:** מוסיפה עמודות חדשות לטבלה או דורסת קיימות בהתבסס על חישובים.
    *   **פרמטרים:** ביטויי השמה, שניתן לשרשר (למשל `pl.when().then().otherwise()`).
    *   **מחזירה:** אובייקט `polars.DataFrame` חדש עם העמודות שנוספו.

**דוגמאות מהפרויקט שלך:**
```python
# סינון שורות כדי להשאיר רק הלוואות שהסתיימו
df = df.filter(pl.col('loan_status').is_in(['Fully Paid', 'Charged Off']))

# יצירת עמודת המטרה (Target) בעזרת תנאי הלוגיקה המהירים של Polars
df = df.with_columns(
    pl.when(pl.col('loan_status') == 'Charged Off').then(1).otherwise(0).alias('target')
)
```

## 3. Matplotlib (`plt`)
ספריית הליבה לשרטוט גרפים. עובדת בשיטה של בניית מרכיבים (Figure - המסגרת הכללית, Axes - מערכת הצירים עצמה).

### פונקציות מרכזיות ושימושיות:
*   **`plt.subplots(nrows, ncols, figsize)`**
    *   **עושה:** יוצרת מסגרת כללית אחת (Figure) ובתוכה רשת של תתי-גרפים (Axes). מעולה להצגת השוואות.
    *   **פרמטרים:** `nrows` (כמות שורות), `ncols` (כמות עמודות), `figsize` (גודל החלון כ-Tuple של רוחב, גובה).
    *   **מחזירה:** `Figure` ורשימה (או מטריצה) של `Axes`.
*   **`ax.plot(x, y, color, label)` / `ax.bar(x, height)` / `ax.scatter(x, y)`**
    *   **עושה:** מציירות בהתאמה גרף קווים, גרף עמודות או גרף פיזור (נקודות).
    *   **פרמטרים:** מערכי הנתונים של צירי ה-X וה-Y, צבעים וטקסט ל-Legend.
    *   **מחזירה:** אובייקטים פנימיים המייצגים את הצורות (למשל `Line2D`).
*   **`plt.title()`, `plt.xlabel()`, `plt.ylabel()`**
    *   **עושה:** מוסיפה כותרות לגרף ולצירים.
*   **`plt.tight_layout()`**
    *   **עושה:** מסדרת את הגרפים כך שלא יחפפו אחד עם השני, מתקנת מרווחים אוטומטית לפני התצוגה.

**דוגמאות מהפרויקט שלך:**
```python
# יצירת חלון תצוגה עם 2 תתי-גרפים 
fig, axes = plt.subplots(1, 2, figsize=(16, 5))

# שרטוט גרף עמודות על הגרף השמאלי (axes[0])
axes[0].bar(labels, target_counts['count'].to_list(), color=colors, edgecolor='white')
axes[0].set_title('Target Distribution (Training Set)', fontsize=14)

plt.tight_layout()
plt.show()
```

## 4. Seaborn (`sns`)
עוטפת את Matplotlib ומוסיפה אסתטיקה וקיצורי דרך לגרפים סטטיסטיים (כמו הוספת צבע לפי משתנה קטגוריאלי בצורה חלקה).

### פונקציות מרכזיות ושימושיות:
*   **`sns.histplot(data, x, bins, kde, hue)`**
    *   **עושה:** משרטטת היסטוגרמה (התפלגות תדירויות של משתנה רציף).
    *   **פרמטרים:** `data` (טבלת Pandas), `x` (שם העמודה), `bins` (מספר העמודות), `kde=True` (יוסיף קו החלקה שמייצג את פונקציית צפיפות ההסתברות), `hue` (צביעה לפי משתנה שלישי).
    *   **מחזירה:** אובייקט `Axes`.
*   **`sns.boxplot(data, x, y)`**
    *   **עושה:** מציירת גרף קופסה המציג את החציון, רבעונים וערכים חריגים (Outliers).
*   **`sns.heatmap(data, annot, cmap)`**
    *   **עושה:** מציירת מפת חום, מעולה להצגת מטריצות מתאם (Correlation).
    *   **פרמטרים:** `data` (מטריצה מספרית), `annot=True` (ידפיס את המספרים בתוך הריבועים), `cmap` (סקאלת צבעים, למשל 'coolwarm').

**דוגמאות מהפרויקט שלך:**

sns.heatmap(full_corr_matrix, annot=True, fmt='.2f', cmap='coolwarm', vmin=-1, vmax=1)

## 5. Scikit-Learn (`sklearn`)
ספריית הבסיס העשירה ביותר לאלגוריתמי Machine Learning קלאסיים. עובדת בשיטת אחידה של אובייקטים בעלי פונקציות `fit` ו-`transform/predict`.

### פונקציות מרכזיות ושימושיות:
*   **`StandardScaler().fit_transform(X)`**
    *   **עושה:** מבצעת Z-score Normalization. היא "לומדת" (fit) את הממוצע וסטיית התקן מהקלט ומחזירה (transform) את הנתונים לאחר חיסור הממוצע וחלוקה בסטיית התקן (מביאה לסולם של ממוצע 0, סטיית תקן 1).
    *   **פרמטרים:** `X` (מערך הנתונים).
    *   **מחזירה:** מטריצה מנורמלת (`np.ndarray`).
*   **`train_test_split(X, y, test_size, random_state)`**
    *   **עושה:** מפצלת את הנתונים אקראית לסט אימון וסט בדיקה. בפרויקט שלך בחרת לעשות פיצול זמני (OOT) בעצמך, אך פונקציה זו היא הסטנדרט בתעשייה לפיצול רגיל.
*   **`KMeans(n_clusters, random_state).fit_predict(X)`**
    *   **עושה:** מפעילה את אלגוריתם KMeans Clustering ללמידה לא-מונחית.
    *   **פרמטרים:** `n_clusters` (מספר הקבוצות שרוצים ליצור).
    *   **מחזירה:** מערך הכולל את התוויות (0, 1, 2...) שניתנו לכל שורה (הקבוצה אליה שויכה).
*   **`PCA(n_components).fit_transform(X)`**
    *   **עושה:** Principal Component Analysis - הורדת ממדים. ממירה מרחב נתונים בעל ממדים רבים למרחב עם פחות ממדים, תוך שימור מקסימום שונות (Variance).
    *   **פרמטרים:** `n_components` (מספר הממדים הסופי הרצוי).
*   **`roc_auc_score(y_true, y_score)`**
    *   **עושה:** מחשבת את הציון של שטח מתחת לעקומת ROC (מדד לאיכות מודל סיווג בינארי).
    *   **פרמטרים:** המטרות האמיתיות (0 או 1), מול ההסתברויות שהמודל חזה (ערכים בין 0 ל-1).

**דוגמאות מהפרויקט שלך:**
```python
# 1. נרמול הנתונים
scaler = StandardScaler()
X_scaled = scaler.fit_transform(df_unsup)

# 2. אימון אלגוריתם KMeans Clustering לזיהוי 3 פרסונות של לווים
km = KMeans(n_clusters=3, random_state=42, n_init=10)
labels = km.fit_predict(X_scaled)

# 3. דחיסת הנתונים ל-2 ממדים בעזרת PCA לשם הצגה גרפית 
pca = PCA(n_components=2, random_state=42)
X_pca = pca.fit_transform(X_scaled)
```

## 6. LightGBM (`lgb`)
אלגוריתם עצים מתקדם מסוג Gradient Boosting מבית מיקרוסופט. היתרון שלו הוא בבניית עצים בשיטת "Leaf-wise" בניגוד ל"Level-wise" הרגיל, מה שהופך אותו למהיר במיוחד.

### פונקציות מרכזיות ושימושיות:
*   **`lgb.LGBMClassifier(**params)`**
    *   **עושה:** מגדירה אובייקט של מודל סיווג.
    *   **פרמטרים (מילון `params`):** `learning_rate` (קצב הלמידה), `n_estimators` (כמה עצים לבנות), `max_depth` (עומק מקסימלי לעץ), `num_leaves` (כמות העלים בעץ), ועוד.
*   **`model.fit(X, y, eval_set, callbacks)`**
    *   **עושה:** מאמנת את מודל העצים.
    *   **פרמטרים:** הנתונים (`X`,`y`), סט ולדיציה (`eval_set`) שמסייע בניטור ביצועים תוך כדי אימון כדי למנוע Overfitting (למשל על ידי עצירה מוקדמת `early_stopping`).
*   **`model.predict_proba(X)`**
    *   **עושה:** מפעילה את המודל המאומן על נתונים חדשים. במקום להחזיר 0 או 1 באופן מוחלט, היא מחזירה את ההסתברות (באחוזים) השייכת לכל מחלקה (מצוין למערכות סיכון בנקאיות).

**דוגמאות מהפרויקט שלך:**
```python
# אתחול מודל סיווג Gradient Boosting עם פרמטרים מותאמים
model = lgb.LGBMClassifier(**params, random_state=42, verbose=-1)

# אתחול המודל הסופי לאחר מציאת הפרמטרים האופטימליים (Tuning)
final_lgbm = lgb.LGBMClassifier(**best_params, random_state=42, verbose=-1)
final_lgbm.fit(X_train, y_train)
```

## 7. Optuna
ספרייה אוטומטית שנועדה למצוא את ההיפר-פרמטרים הטובים ביותר למודל שלך באמצעות למידה בייסיאנית (היא "לומדת" מניסויים קודמים כדי לנחש אילו פרמטרים כדאי לנסות עכשיו, בניגוד ל-Grid Search שעובר על הכל כוח-גס).

### פונקציות מרכזיות ושימושיות:
*   **`optuna.create_study(direction)`**
    *   **עושה:** יוצרת אובייקט שמנהל את הניסוי.
    *   **פרמטרים:** `direction` (האם להגדיל ערך מסוים כמו AUC ('maximize'), או להקטין שגיאה כמו RMSE ('minimize')).
*   **`trial.suggest_float(name, low, high)` / `trial.suggest_int()`**
    *   **עושה:** מגדירה לאופטונה בתוך פונקציית המטרה מאילו טווחי מספרים מותר לה לדגום פרמטרים במהלך הניסוי (למשל קצב למידה בין 0.01 ל 0.1).
*   **`study.optimize(objective, n_trials)`**
    *   **עושה:** מתחילה את ריצת החיפוש! מריצה את פונקציית ה-`objective` כמספר הפעמים המוגדר ב-`n_trials`.

**דוגמאות מהפרויקט שלך:**
```python
# יצירת "מחקר" המכוון למקסם את המדד (AUC)
study = optuna.create_study(direction='maximize')

# הרצת תהליך החיפוש האוטומטי
study.optimize(objective, n_trials=20)

# שליפת המילון המכיל את הפרמטרים המנצחים!
best_params = study.best_params
```

## 8. TensorFlow / Keras (`tf`)
פלטפורמת הקוד הפתוח של גוגל ללמידת מכונה, ספציפית לבניית רשתות נוירונים עמוקות.

### פונקציות מרכזיות ושימושיות:
*   **`Sequential(layers)`**
    *   **עושה:** מייצרת אובייקט של מודל עוקב – הזרמת המידע מתבצעת שכבה אחר שכבה ברצף.
*   **`Dense(units, activation)`**
    *   **עושה:** שכבה "צפופה" (Fully Connected) שבה כל נוירון מחובר לכל הנוירונים מהשכבה הקודמת.
    *   **פרמטרים:** `units` (כמות הנוירונים בשכבה), `activation` (פונקציית האקטיבציה, לרוב `relu` באמצע ו-`sigmoid` ביציאה לסיווג בינארי).
*   **`Dropout(rate)`**
    *   **עושה:** שכבת מניעת Overfitting. מכבה באקראי נוירונים (למשל בשיעור של 0.2) במהלך האימון כדי להכריח את הרשת ללמוד פיצ'רים כלליים יותר.
*   **`model.compile(optimizer, loss, metrics)`**
    *   **עושה:** אוספת את המבנה של הרשת ומכינה אותו לחישובים המתמטיים.
    *   **פרמטרים:** `optimizer` (למשל 'adam' שאחראי על עדכון המשקולות), `loss` ('binary_crossentropy' בבעיות זיהוי כן/לא), `metrics` (מה להדפיס למסך כמו 'accuracy').
*   **`model.fit(x, y, epochs, batch_size)`**
    *   **עושה:** מתחילה לאמן את המשקולות דרך מעבר קדימה ואחורה ברשת (Backpropagation).
    *   **פרמטרים:** `epochs` (כמה פעמים לעבור על כל בסיס הנתונים), `batch_size` (כמה דוגמאות להכניס בבת אחת בכל חישוב צעד משקולות).

**דוגמאות מהפרויקט שלך:**
```python
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense, Dropout, BatchNormalization

# רשת נוירונים עמוקה שהרכבת
model = Sequential([
    Dense(128, activation='relu', input_shape=(X_train_scaled.shape[1],)),
    BatchNormalization(),
    Dropout(0.3),
    Dense(64, activation='relu'),
    Dropout(0.2),
    Dense(1, activation='sigmoid') # יציאה שמחזירה הסתברות
])

# קימפול (הכנה לאימון)
model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['AUC'])
```
